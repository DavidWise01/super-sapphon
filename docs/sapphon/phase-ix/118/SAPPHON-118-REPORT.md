## Delivered
- `tools/sapphon_118_anchor.cjs` implements an independently *stored but not independently operated* local checkpoint journal. A provisioned Ed25519 checkpoint signer binds a receiver identifier, state revision, complete receiver JSON SHA-256, custody-root declaration, and previous checkpoint digest.
- Each published checkpoint must increase the receiver revision strictly, match the previous checkpoint link, and carry a valid signature under the explicitly provided anchor public-key registry. Duplicate retry of the latest signed checkpoint returns `ALREADY_ANCHORED` without adding records.
- `compare` checks receiver state against the latest trusted synthetic checkpoint and refuses a lower receiver revision (`RECEIVER_ROLLBACK_DETECTED`), a conflicting same-revision digest (`RECEIVER_STATE_CONFLICT`), or an unanchored newer revision (`UNANCHORED_RECEIVER_ADVANCE`).
- The checkpoint store uses an exclusive local directory lock, temporary-file write, file fsync, atomic rename, and directory fsync. It rejects corrupt manifests, missing anchors, altered chain links, unauthorized signers, revoked roots, and forged signatures.

## Source and qualification boundary

The checkpoint journal is a **separate local filesystem directory**, not an independently authenticated outside organization or hardware monotonic counter. Its custodian keys are generated by the synthetic test fixture. This distinction is material: after making two valid receiver checkpoints, the test restores both receiver and local checkpoint files to an earlier mutually consistent state. The verifier accepts that state, demonstrating that **joint rollback remains possible** without an independently held high-water mark.

The verification also does not lock the receiver and checkpoint directories as one distributed transaction, so simultaneous writes require a further coordination protocol. SHA-256 and signatures detect inconsistent evidence only relative to trusted, preserved key and checkpoint history; they cannot themselves prove physical measurement, genuine offsite custody, wall-clock accuracy, or UTC.

**External anti-rollback authority: HOLD. Independently controlled custody: HOLD. Global transaction authority: HOLD. Calibrated physical clock and UTC: HOLD.**
